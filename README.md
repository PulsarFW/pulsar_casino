## Overview

Registers `plsr.Casino`. Blackjack, roulette, and slots each get their own client/server pair; chip purchases, the Lucky Wheel (with a vehicle prize tier), and win/loss records round out the rest.

---

## Dependencies

- `pulsar_core` — framework core
- `pulsar_finance` — cash in/out for chips and payouts
- `pulsar_vehicles` — Lucky Wheel vehicle prizes
- `pulsar_pwnzor` — anti-cheat check loaded alongside every resource
